## Network and limits

CATSHIT gameplay is **devnet**. The separate **mainnet SKR** ownership lookup only unlocks cosmetic Nine Lives access; it requests no SKR transaction and gives no CATSHIT reward advantage. Devnet SOL is needed for transaction fees and rent. RPC availability and retained history can limit indexing/verification.

The project is publicly verifiable, not fully trustless: centralized publisher, upgradeable unaudited program, no on-chain fraud-proof challenge. Existing dependency advisories remain documented. **Code license: not selected.** Music source/license information is in [MUSIC-CREDITS](../app/assets/room-skr-club/MUSIC-CREDITS.md); no blanket license is granted for other media.
