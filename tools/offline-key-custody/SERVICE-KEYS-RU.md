# YAMC — отдельные служебные ключи mainnet

Этот пакет создаёт адреса, но НЕ транзакции и НЕ deployment. Интернет и npm install
не нужны: используется только установленный Node.js и его встроенная криптография.
Запускайте на том же отдельном отключённом от сети компьютере. Не используйте
папку существующих admin/program/mint: они остаются без изменений.

## Создание

Откройте PowerShell в распакованной папке пакета:

```powershell
node .\service-keys.mjs generate .\yamc-mainnet-service-keys
node .\service-keys.mjs verify-public .\yamc-mainnet-service-keys\service-public-identities.json
```

Существующий каталог не перезаписывается. При сбое не смешивайте частично созданные
файлы с другим набором: остановитесь и сообщите ошибку без содержимого ключей.

Будут созданы шесть независимых ключей:

| Файл | Роль и будущее размещение |
| --- | --- |
| payer.json | Оплата deployment, только контролируемый рабочий компьютер |
| uploadAuthority.json | Временная подпись записи buffer, только рабочий компьютер |
| publisher.json | Публикация reward roots, только publisher-сервис |
| issuer.json | Подпись faucet-разрешений, только admission-сервис |
| buffer.json | Создание временного buffer, только подготовка deployment |
| nonceAccount.json | Создание nonce-аккаунта, не право распоряжаться nonce |

Authority nonce будет существующий offline admin. Ключ nonceAccount сам по себе
не позволяет подписывать nonceAdvance после назначения authority.
Publisher и issuer позже станут online-ключами: offline-генерация не защищает от
последующей компрометации сервисного хоста. Их ротация выполняется отдельно.

## Резервная копия

Сохраните всю папку yamc-mainnet-service-keys на отдельном защищённом носителе.
Ключи — обычные незашифрованные Solana JSON: требуется защищённое хранение/носитель.
Не отправляйте эту папку в облако, Git, чат или на обычную флешку для обмена.
Проверьте именно скопированную папку; замените путь E: на свой:

```powershell
node .\service-keys.mjs verify-backup E:\yamc-mainnet-service-keys .\yamc-mainnet-service-keys\service-public-identities.json
```

Ожидается BACKUP_VERIFIED. Если защищённое хранилище сохраняет файлы в контейнере,
проверка выполняется по доступному пути после его разблокировки.

## Что вернуть

Только `service-public-identities.json` скопируйте на рабочий ПК в:

```text
temp\mainnet-service-identities-return\service-public-identities.json
```

Сообщите, что резервная копия проверена. Файл содержит только публичные ключи и
подписи отдельного текстового proof, не пригодные для исполнения транзакции.
Не возвращайте шесть секретных JSON! Их выборочный защищённый перенос на рабочую
машину/сервисы подготовим отдельно после проверки адресов. Ничего не пополняйте SOL.

`expected-existing-identities.json` содержит уже выбранные публичные admin/program/
mint. Он нужен для сверки неизменности старого набора; его НЕ нужно генерировать заново.
