# YAMC — зашифрованный перенос ключей deployment

Пакет переносит только payer, uploadAuthority, buffer и nonceAccount на рабочий ПК.
Publisher и issuer пока остаются офлайн. Admin/program/mint никогда не копируются.
Никаких транзакций, пополнения SOL или установки на VPS этот шаг не выполняет.

## На отдельном офлайн-компьютере

1. Распакуйте пакет в новую папку. Существующие папки ключей не перемещайте.
2. Сверьте отпечаток получателя с указанным в сообщении ассистента:

```text
6fb95ec89dc3da4eba5ff07a7736091f4e1d6f08de89b29ee78fc8d0274eb9d9
```

Это SHA256 DER/SPKI публичного RSA-ключа, не SHA256 текстового PEM файла.
3. Откройте PowerShell в папке пакета. Выполните команду ниже, заменив оба пути
   `D:\YAMC\yamc-mainnet-service-keys` на фактическую папку служебных ключей:

```powershell
node .\transfer.mjs seal-deployment "D:\YAMC\yamc-mainnet-service-keys" "D:\YAMC\yamc-mainnet-service-keys\service-public-identities.json" .\recipient-public.pem 6fb95ec89dc3da4eba5ff07a7736091f4e1d6f08de89b29ee78fc8d0274eb9d9 .\deployment-roles.enc.json
```

Ожидается `ENCRYPTED_DEPLOYMENT_ROLES_ONLY`. Интернет и npm install не нужны.
Скрипт читает только четыре разрешённых файла и проверяет их адреса по вашему
исходному публичному реестру. Старые результаты не перезаписываются. При ошибке
остановитесь и сообщите текст ошибки, не содержимое ключей.

## Что вернуть

Только созданный `deployment-roles.enc.json` положите на рабочем ПК в:

```text
temp\mainnet-deployment-transfer-return\deployment-roles.enc.json
```

Не копируйте секретные JSON, всю папку ключей, publisher/issuer или admin/program/mint.
Резервные копии сохраняются как раньше. Этот зашифрованный файл — транспортная копия,
не замена бэкапа. Приватный ключ расшифровки остаётся на рабочем ПК; в пакете его нет.

Используются RSA-4096 OAEP/SHA256 для случайного ключа и AES-256-GCM для содержимого.
Шифрование защищает файл в пути, но после расшифровки эти четыре ключа станут online:
безопасность рабочего ПК остаётся важной. Шифрование не скрывает доступ к самому
рабочему ПК от его владельца/администратора. Ничего пока не пополняйте SOL.
